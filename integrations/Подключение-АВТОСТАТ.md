# Подключение АВТОСТАТ для ФАС торги

Выбран сервис: https://www.autostat.ru/research/product/381/
Статус: не подключён, договор и доступ отсутствуют.

У поставщика необходимо получить:
- Условия доступа к API и право отображать результат посетителям аукциона.
- Документацию запросов, авторизации и справочников модификаций.
- Тестовый доступ, ограничения частоты и тариф на ожидаемый объём оценок.
- Состав результатов: рыночная стоимость, диапазон, дата данных, цена быстрой продажи.

После получения доступа:
1. Добавить серверный runtime сайта и хранение секрета через защищённые настройки.
2. Добавить проверяемые характеристики активов и серверный доступ банка/менеджера.
3. Реализовать адаптер по фактической документации, не использовать контракт другого поставщика.
4. Кэшировать оценку по характеристикам и дате; обновлять при их изменении.
5. Показывать источник, дату, диапазон и отклонение текущей ставки от оценки.
6. При ошибке API показывать «оценка недоступна», не подставлять цену продавца.

Ключи нельзя присылать в чат, хранить в браузере или коммитить.
Автоматическая оценка не заменяет проверку состояния и юридических ограничений имущества.
Данная документация не является подтверждением подключения или наличия AI у поставщика.
