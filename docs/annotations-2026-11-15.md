# Аннотации каталога: регионы, карта и компоновка

Изменения поверх опубликованной v69 (`d72e2173058e524f125eaadbeb1ed9f07c6b0eda`). Пользовательские объявления, фотографии, ставки и черновики не мигрируются и не удаляются. Сервер Worker и привязка D1 сохраняются.

## Поведение для посетителя

- В поиске откройте «Вся Россия». Галочками можно выбрать любой набор регионов, найти регион по имени и подтвердить выбор кнопкой «Применить». Общая галочка выбирает все регионы. Снимите её, чтобы начать выбор с пустого списка. Пустой набор нельзя применить. Escape или нажатие вне списка отменяет неподтверждённые изменения.
- Лоты разных выбранных регионов объединяются. Город, категория, цена и остальные условия продолжают сужать выдачу. Набор восстанавливается после перезагрузки, возврата из ленты и при работе с сохранённым поиском.
- Блок «Федеральная аукционная сеть» содержит схематичную карту России с Москвой и связями с региональными центрами. На широком экране карта справа, на телефоне ниже текста.
- В верхней ленте выделены карточки и переключатели подборок: выбранная вкладка синяя, остальные имеют заметные границы. Логика рекомендаций и жестов не меняется.
- Заголовок каталога, переключатели вида, фильтры и сортировка объединены в одну панель. Обычные карточки шире, цена выделена, характеристики сгруппированы, таймер стал единым блоком. На ширине 787 px выводятся две колонки, на телефонах — одна.

## Где менять код

| Файл | Назначение |
| --- | --- |
| `dist/region-select.js`, `dist/region-select.css` | Общий API регионов и интерфейс списка с галочками |
| `dist/index.html`, `dist/app-ui.js` | Подключение модуля, фильтрация, города, подготовка поиска, сохранение/восстановление |
| `dist/catalog-refresh.css` | Оформление верхней ленты, панели каталога и обычных карточек |
| `dist/network-intro.css` | Адаптивная компоновка блока с картой |
| `dist/assets/russia-network.svg` | Статическая иллюстрация без запросов и JavaScript |
| `scripts/generate-russia-network.mjs` | Воспроизводимое создание карты из сохранённой геометрии и справочника |
| `dist/sw.js` | Версия публичного статического кэша и типы новых ресурсов |

Модуль регионов подключается сразу после `catalog-data.js`, до основного inline-кода. Существующий `#region-filter` остаётся каноническим полем: пустая строка — вся страна, один код — прежний одиночный выбор, несколько кодов — отсортированная строка через запятую. Все 85 выбранных кодов нормализуются во «Вся Россия». Регион пользователя для расстояний и адрес продавца остаются отдельными однозначными значениями. Подробности и случаи повреждённых данных: [регионы](region-multiselect-2026-11-15.md).

Карта содержит 85 точек существующего справочника: Москва и 84 других центра, соединённых тонкими линиями. Это географическая иллюстрация, а не счётчик реально подключённых отделений или продавцов. Источник контура, проекция, лицензия и контрольные суммы: [география карты](russia-network-geography-2026-11-15.md).

Стили обычного каталога ограничены `body:not(.reels) #grid` и его панелью. Полноэкранная лента и диалоговые окна сохраняют собственную компоновку; кнопки, обработчики, защита несохранённых форм и данные не заменяются. Новый CSS подключается последним, чтобы область переопределений была видна разработчику.

## Проверка и выпуск

- Девять профильных файлов тестов регионов, поиска, подписок, геолокации и возврата — PASS.
- Браузерный выбор 3/5/84/85 регионов, фактическая OR-выдача, reload, сброс и отмена — PASS на 1366/390/320 px. Первоначальное выступание панели на 1 px при 320 px исправлено и перепроверено.
- Карта и адаптивность — PASS на 1366/787/390/320 px; поиск получает фокус и ввод, лот верхней ленты открывается; ошибок JavaScript нет.
- Панель каталога и карточки проверены на тех же четырёх ширинах: 4/2/1/1 колонки соответственно, фотографии сохраняют высоту, кнопка участия доступна после обычной прокрутки. На 320 px исправлены перенос заголовка посреди слова и переполнение вкладки «Избранное»; повтор на 320/390 px прошёл. Стили полноэкранной ленты совпадают с вариантом без нового CSS.
- Перед публикацией выполняется штатный pre-push: 100 изолированных модельных участников и все десять `security-*.cjs`. Проверка не отключается; публикация разрешена только при успешном результате.

Браузерные артефакты находятся вне исходников в `network-intro-browser` каталога рабочей сессии. Мобильные размеры в Chrome не заменяют физические испытания Safari/iOS и Android. Этот выпуск меняет веб-сайт: отдельные APK/IPA не пересобирались. Установленные нативные приложения сохраняют прежнюю встроенную сборку до отдельного обновления. Совместные серверные торги и реальные платежи этим выпуском не добавляются.

Снимок сохраняется штатным workflow Sites и затем в отдельной ветке приватного GitHub; прежняя main и резервные ветки сохраняются. Для отката можно повторно развернуть сохранённую v69. Старые одиночные значения региона остаются совместимыми, новые составные значения следует открывать версией с `FasRegions`; перед откатом клиентского кода сбросьте региональный фильтр во «Вся Россия».
