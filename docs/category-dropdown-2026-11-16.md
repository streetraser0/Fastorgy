# Выпадающий список категорий в поиске — 16.11.2026

Основа — опубликованная v74, коммит `4c429a7b2f463a8ada68c6bc718f221d02b505fb`.

Поле «Все категории» в форме поиска главной страницы раскрывает список непосредственно под полем. Страница остаётся доступной, без затемнения и блокировки прокрутки. Изменение относится к `[data-browse-categories]`; категория объявления продавца и остальные входы в дерево сохраняют прежнее поведение.

Дерево категорий, подкатегории, поиск и выбор нескольких пунктов используют существующие данные. Галочки редактируют предварительный выбор. «Применить» передаёт его существующему фильтру каталога; закрытие без применения не меняет выбранные ранее категории. Переход внутрь группы в выпадающем списке открывает подкатегории, без немедленного изменения каталога.

Повторное нажатие на поле, Escape и нажатие снаружи закрывают список. Кнопка сообщает состояние через `aria-expanded` и связывается со списком через `aria-controls`. Управление с клавиатуры и фокус сохраняются, список ограничен доступной шириной экрана.

Код: `dist/category-ui.js`; отдельное оформление: `dist/category-dropdown.css`, подключённое после общих стилей. Параметр версии скрипта — `20261116-dropdown1`; общий кеш выпуска — `20261116-cabinet-rating1`. Новый CSS включён в список статических ресурсов. Общий сервер торгов, платежи и пользовательские объявления этим изменением не затрагиваются.

Пройдены `category-dropdown`, `category-picker`, `desktop-category-selection`, `category-multi-select`, `category-keyword-search`. В Chrome проверены ширины 1366, 850 и 390 px: применение, отмена, поиск, клавиатура, прежние окна продавца, без ошибок JavaScript. Дополнительно на 390×500 проверена прокрутка пальцем к кнопке «Применить», а на 1366×1000 — доступность кнопки при видимой нижней панели. При недостаточной высоте прокручивается весь список с его действиями; раскрытый список находится выше нижней панели. Проверка телефона выполнена эмуляцией, не на физическом iPhone. Перед публикацией штатный pre-push проверяет точный снимок с 100 изолированными модельными участниками и security-тестами. APK/IPA отдельно не пересобираются.
