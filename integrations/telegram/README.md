# Telegram — подготовленный серверный адаптер

Статус: **не подключён**, бот не создан, токенов и живого webhook нет. Этот каталог не импортируется сайтом или Worker. Название будущего бота — «Фаст Торги», возможный английский вариант — Fast Torgi; доступность `@FastTorgiBot` не проверена.

Модуль `adapter.cjs` содержит проверяемую границу будущей интеграции, а не готовый сервер аккаунтов или очередь. По умолчанию он выключен. Для запуска необходимы защищённая серверная авторизация, постоянное хранилище с атомарными операциями, доверенные события торгов, транспорт и отдельная проверка конфигурации.

Проверка из корня репозитория:

```sh
node integrations/telegram/adapter.test.cjs
```

Тест использует только собственные хранилища в памяти и fake-fetch. Запросов в Telegram и сообщений настоящим пользователям нет. Полный контракт, настройки и последовательность подключения: [руководство](../../docs/telegram-integration.md).
