# Выпадающая сортировка каталога

`dist/catalog-sort-dropdown.js` и `dist/catalog-sort-dropdown.css` оформляют только существующий `select#sort`. Другие списки и алгоритм сортировки не меняются. Кнопка с классом `sort` занимает прежнюю ячейку панели; белое меню с галочкой помещается в `body`, поэтому его не обрезает панель каталога.

Исходный select остаётся источником текущего значения и обработчиком `change`. После выбора нового значения модуль отправляет по одному всплывающему `input` и `change`; повторный выбор текущего значения не вызывает перерисовку. При ошибке инициализации или отсутствии JavaScript исходный список остаётся доступным. Подключить CSS после оформления каталога, JS после основного скрипта страницы. Ключ версии: `20261116-sort1`.

Кнопка имеет семантику select-only combobox, меню — listbox. Стрелки и Home/End перемещают подсветку, Enter/Space и Tab подтверждают, Escape или щелчок вне меню отменяют незавершённый выбор. Поддерживается поиск по началу названия клавишами. Фокус остаётся на кнопке; внешнее нажатие не возвращает фокус насильно. Заблокированные и устаревшие пункты не выбираются.

Синхронизация программных сбросов региона, поиска и ленты наблюдает только замену дочерних узлов существующего `#grid`; опросов или новых запросов нет. Наблюдатель исходного select обрабатывает изменение доступности/пунктов. `window.FasCatalogSort.refresh()` доступен для будущих обновлений значения без перерисовки каталога.

Меню позиционируется относительно кнопки в видимой области экрана, при необходимости раскрывается вверх и ограничивается по высоте над нижней панелью. Resize, scroll и visualViewport обновляют позицию; при уходе кнопки за экран или переходе в полноэкранную ленту меню закрывается. Цвет фокуса — синий, без красной обводки.

Проверка: `node tests/catalog-sort-dropdown.cjs` — родные события, клавиатура/отмена, отключённые и заменённые пункты, программный сброс, отказ инициализации, геометрия 1366/390/320 px и нижняя панель. Реальную вёрстку и клики проверяет общий браузерный прогон.
