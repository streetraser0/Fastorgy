# Мобильный пакет после исправлений возврата и кабинета продавца

Пакет подготовлен из остановленного для проверки снимка после v68. Он включает новый логотип, исправленный возврат вправо с первого фото карточки, изменения продавца/черновиков и актуальные ресурсы сайта. Desktop hover-модуль включён в общие ресурсы, но в мобильной оболочке остаётся отключён своим условием `FasDesktopWeb.active()`.

Выполнены `prepare-web.mjs`, `capacitor sync` для Android/iOS и `check-mobile.mjs`. Android debug APK собран на существующих JDK 21, SDK 36 и Gradle 8.14.3 с параметрами `--offline --no-daemon -Pandroid.overridePathCheck=true`. Сборка прошла за **2 минуты 3 секунды**: 27 задач выполнены, 217 использовали прежние результаты. Ничего дополнительно не устанавливалось.

Побайтовая проверка `mobile/scripts/verify-artifacts.py`: **279 публичных файлов, 1150 проверок, 0 ошибок**. Сравнены исходные публичные ресурсы, подготовленный `mobile/www`, Android assets, iOS public и содержимое APK. Сборочный APK и копия `releases/fas-torgi-android-demo-debug.apk` совпадают.

Сгенерированные Gradle/SPM пути после сборки восстановлены к переносимым относительным путям; файлы конфигурации мобильного проекта не содержат машинных изменений. APK исключён из Git.

Этот APK заменяет предыдущий пакет, описанный в [проверке мобильного кабинета](mobile-cabinet-parity-2026-11-15.md). Сайт не обновляет автоматически уже установленное приложение: нужен новый APK или отдельная iOS-сборка. В текущем прогоне эмулятор и физический телефон не запускались, APK не устанавливался. Ресурсы iOS проверены, но IPA и проверка на iPhone требуют Mac/Xcode и устройства. Успешная сборка и совпадение файлов не означают завершённое тестирование на физическом телефоне.
