# Повторная проверка поиска ФАС торги

Дата: 13 ноября 2026 года. Проверяется демонстрационный сайт, не реальная торговая платформа.

## Подтверждённые исправления

| Ошибка | Поведение после исправления |
| --- | --- |
| Audi принимался за аудиотехнику | Точный алиас Audi важнее основы слова audio; Audi и аудиотехника проверены отдельно |
| Sprinter, Gran, Bolt, Roma исправлялись в посторонние слова | Все известные марки и модели защищены от ошибочного исправления |
| Geely без модели определялся как грузовик | Название марки не считается одновременно названием модели |
| Автокатегория скрывала Xiaomi, Mitsubishi Electric, XCMG, SANY и точные исходные слова | Совпадения проверяются по всем видам имущества, затем уточняется автоматическая категория |
| Ручная категория терялась при повторном открытии сайта | Сохраняется признак ручного выбора; старые настройки без него по-прежнему восстанавливаются безопасно |
| Старый фильтр SITRAK скрывал новый запрос HOWO | Известный новый запрос по марке/модели очищает противоречащие ограничения семейства |
| Марка и город не входили в счётчик параметров | Они видны в счётчике и пояснении поиска |
| Пустые поля сохранённого поиска подменялись текущей категорией и регионом | Явные пустые значения сохраняют поиск по всем категориям/регионам |
| Кадастровые номера совпадали после перестановки частей | Сравнивается полный номер, порядок и ведущие нули |
| Серийный номер собирался из слов разных полей | Требуется целый идентификатор в одном допустимом публичном поле |
| Русские названия китайских моделей не совпадали с английскими | Добавлены подтверждённые варианты Jolion, Monjaro, Coolray, Tugella и других популярных моделей; коды C5/S5 и RX/VX различаются |

## Охват

- Все 521 марка и 8117 моделей из текущего справочника; 24 997 прямых сравнений канонических названий, сочетаний марки/модели и алиасов.
- Все 31 категория и 39 уникальных предметных названий текущих демопримеров.
- Русские и английские запросы, опечатки и неверная раскладка, номера, единицы измерения, неоднозначные названия и сохранённые поиски.
- Полный последовательный прогон 79 сценариев интерфейса и SQLite/backend; после добавления 80-го сценария отдельно повторены целевые проверки движка и русских названий китайских моделей.

## Практические границы

Совпадение справочника не создаёт объявление. Например, отсутствие предложения холодильника в текущих демоданных не исправляется показом стиральной машины. Поиск по заданным цене, региону и расстоянию также может корректно вернуть ноль.

В источнике есть спорные классификации JCB/Kubota и неоднозначные самостоятельные названия моделей вроде Truck/Business. Их не маскировали изменением общего смысла слов. Автоматическая категория учитывает фактические найденные записи; явно выбранное ограничение категории остаётся строгим.

Это набор автоматических регрессионных и сквозных проверок данных/DOM, не доказательство отсутствия всех будущих ошибок. Прогон на физических iPhone/Android и визуальная проверка Safari в этой среде не выполнены. Новые марки и модели требуют обновления справочника и алиасов.
