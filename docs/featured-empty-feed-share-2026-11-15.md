# Пустая подборка и действие «Поделиться» в верхней ленте

## Пустая подборка

На Android последовательность «Дешевле» → «Вся лента» могла завершаться без видимой реакции. Такое же поведение воспроизводилось с сохранёнными режимами `["low"]` и `["low","ending"]`: `FasFeaturedLots.openFeed()` корректно не открывал ленту при отсутствии подходящих лотов, но молча возвращал `false`.

При таком нажатии теперь показывается сообщение «По выбранным условиям лотов нет. Измените условия подборки.», а страница прокручивается к объяснению пустой подборки и фокусирует кнопку «Изменить условия». Эта кнопка также доступна непосредственно в пустой подборке. Только отдельное нажатие открывает существующую панель `FasFeaturedSettings`; если модуль недоступен, используется существующее открытие поиска. Открытие панели останавливает всплытие этого клика, чтобы её штатный обработчик нажатия снаружи сразу не закрыл панель.

Существующее действие «Выбрать категорию» для пустого режима «Дешевле» сохранено. Режимы, фильтры, регион, история и интересы не сбрасываются. Критерии по-прежнему сочетаются через AND; неподходящие лоты и чужие категории не подставляются, пустая полноэкранная лента не открывается. Пользователь может явно изменить параметры или снять выбранный режим.

## Поделиться из верхней ленты

В карточках верхней ленты после сердечка добавлена `.featured-share[data-buyer-share]`. Кнопка использует существующий делегированный обработчик `buyer-tools.js`. Для действующих исходных публичных демолотов (`demo === true`, без `demoEdited` и `sellerOwnerId`) показаны значок обмена и подпись «Поделиться». Для локальных, изменённых и принадлежащих пользователю объявлений показаны копирование и «Номер лота»; публичная ссылка для них не создаётся. Изменение признака публичности обновляет подпись карточки. Контроль доступности и очистка параметров URL остаются в существующем модуле действий покупателя.

## Проверки

После изменений выполнены **18 файлов тестов, все PASS**: все `tests/featured-*.cjs`, `tests/desktop-featured-personalization.cjs` и `tests/buyer-tools.cjs`. Полный набор проекта повторно не запускался в рамках этой правки.

- `tests/featured-empty-feed.cjs` проверяет реальные модули подборки, рекомендаций и настроек: свежее состояние Android, сохранённые `low` и `low + ending`, настоящую историю просмотра недвижимости, явный результат кнопки «Вся лента», сохранность данных, открытие панели через всплывающий клик, повторные попытки, сознательное снятие режима и непустые контрольные сценарии iOS/desktop.
- `tests/featured-share.cjs` проверяет карточки вместе с реальным обработчиком `buyer-tools.js`: клик по вложенной подписи, публичную очищенную ссылку, копирование только номера для локальных/изменённых/принадлежащих пользователю объявлений, независимость сердечка, отсутствие побочного открытия лота/записи истории и отказ для уже недоступного лота.
- Остальные проверки покрывают действующие комбинации режимов, возврат из ленты, персонализацию desktop и сохранение мобильной логики, прокрутку и фотоальбомы, кеш, фильтры и существующие действия покупателя. Физические жесты и геометрию отдельно проверяет браузерный QA.
