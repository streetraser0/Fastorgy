# Логотип, кабинет телефона и карточка лота — 15 ноября 2026

## Что изменилось для посетителя

- Новый логотип «ФАС торги»: наклонные светлые буквы с тёмной обводкой, серебристый овал и сохранённый знак из трёх уровней. На светлом фоне, фотографии и тёмной ленте используется одно изображение.
- Android и iPhone используют одинаковую компоновку кабинета: разделы слева, содержимое справа, «Мои черновики» отдельной вкладкой; в разделе всех объявлений список черновиков раскрывается снизу.
- Карточка лота группирует фотографии, характеристики и цену с действиями. Правила ставок, избранное, просмотр оригинальных фотографий и возврат через верхнее окно сохраняются.

- В пустой подборке «Вся лента» показывает причину и действие «Изменить условия»; изменение фильтров остаётся явным выбором пользователя. Под сердцем верхних карточек добавлена безопасная отправка ссылки или копирование локального номера. [Подробности](featured-empty-feed-share-2026-11-15.md).
- В просмотре фотографий свайп вниз при 100%, вправо с первого кадра и нажатие на свободное поле возвращают к карточке. Масштабирование и перелистывание сохраняются. [Правила жестов](photo-return-fix-2026-11-15.md).
- На всех платформах транспорт показывает тип двигателя, объём и мощность в л.с. / кВт. Отсутствующие значения не угадываются. [Данные и единицы](vehicle-engine-facts-2026-11-15.md).

## Пересборка и доставка

1. После изменения рисунка выполнить из корня `node scripts/generate-brand-logo.mjs`. Не помещать большой мастер в `dist`.
2. Из `mobile` выполнить `npm run sync`, затем `npm run check`. Это переносит единый web bundle в Android и iOS; вручную сгенерированные `www`/`public` не редактировать.
3. Android APK пересобрать существующим Gradle wrapper с JDK 21/SDK 36. Для iOS бинарной сборки требуются macOS/Xcode. Обновление сайта не обновляет уже установленный старый APK/IPA.
4. Проверить кабинет, черновики, галерею, возврат и размещение на обоих типах телефона. Диагностика с подменой user-agent не заменяет проверку физического Safari/WebView.
5. При выпуске сайта обновляется версия кэша в `dist/sw.js`; навигация, личные данные и запросы ставок не становятся офлайн-кэшем. Sites публикуется штатным workflow из текущего источника; его аудитория сохраняется.

## Данные и ограничения

Схема localStorage/IndexedDB и содержимое объявлений не мигрируют и не очищаются. Поведение сайтового кабинета подключено к существующим кнопкам и формам. Общий серверный кабинет, SMS, платежи и настоящие денежные торги этим изменением не добавляются. Резервная копия исходников GitHub не содержит локальные фотографии посетителей или секретные ключи.

## Проверки текущего изменения

Браузер: 8/8 сценариев логотипа/кабинета и 8/8 сценариев карточки лота прошли; четыре сравнения компоновки iOS/Android/native совпали. Ошибок JavaScript в итоговом прогоне нет. Проверены ширины 320, 390, 412 и desktop 1366, сохранение фотографии черновика после reload, защита профиля, просмотр оригинала/масштаб/возврат.

В первом браузерном прогоне обнаружена ошибка `insertBefore`: три дополнения карточки ожидали цену непосредственно в `.purchase-body`. В `buyer-tools.js`, `seller-ratings.js` и `messages.js` вставка привязана к фактическому родителю; дополнительные сведения находятся в `.lot-detail-facts`. `tests/lot-detail-decorators.cjs` проверяет 4 варианта реального DOM, включая старую разметку. Первый общий прогон остановлен после обнаружения ошибки; он не считается успешным выпускным прогоном.

Общий прогон основы этого изменения: 219 из 220 файлов прошли на неизменённом production-снимке; единственный отказ исправлен в тестовых данных и успешно повторён отдельно, как описано ниже. Позднее добавленные исправления пустой ленты, отправки ссылки, жестов и двигателя проверяются отдельными целевыми наборами; полный набор после каждой такой правки не повторяется. [Машинный аудит общего прогона](brand-mobile-test-audit-2026-11-15.json), [браузерные сценарии](brand-mobile-browser-audit-2026-11-15.json). Результаты v67 не подменяют проверки этого изменения.

В текущем общем прогоне обнаружена нестабильность fixture `tests/cross-tab-auctions.cjs`: две отдельные операции `Date.now()` задавали предполагаемый часовой срок, который при разнице в 1 мс становился короче допустимого минимума. Из-за этого проверка не доходила до ожидаемого отказа записи из другой вкладки. Fixture исправлен одним сохранённым timestamp; исходный assert, правило минимальной длительности и production-код сохранены. Изолированный повтор после исправления прошёл за 18 302 мс. Отчёт `brand-mobile-cross-tab-repeat.json` в каталоге артефактов содержит stdout, время и SHA-256 теста, harness и связанных production-источников до/после запуска; источники во время повтора не менялись. Этот повтор учитывается отдельно от исходного общего прогона.


Финальная проверка мобильного пакета: 278 общих ресурсов, 1146 успешных сверок; debug APK пересобран офлайн с последними жестами, отправкой ссылки и блоком двигателя. Контрольная сумма и ограничения запуска на устройствах — [отчёт мобильной сборки](mobile-cabinet-parity-2026-11-15.md). iOS-ресурсы синхронизированы; бинарная iOS-сборка в Windows не выполнялась.
