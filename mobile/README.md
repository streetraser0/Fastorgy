# ФАС торги — Федеральная аукционная сеть

## Утверждённый логотип от 16 ноября 2026

Общий сайт использует центральную композицию: исходная трёхъярусная пирамида сверху, синий градиент, мягкий блик и надпись «ФАС торги». Векторный оригинал находится в `../design/brand/fas-torgi-centered-gradient-master.svg`; буквы переведены в контуры. Из исходника обрезаются только прозрачные поля. Значки приложения используют пирамиду, заставки — полный логотип.

Из корня проекта: `node scripts/generate-brand-logo.mjs`, затем `node scripts/generate-native-brand.mjs`; после изменений сайта выполнить `npm run sync` из каталога `mobile` и `npm run check`. Синхронизация обновляет исходники и встроенные ресурсы Android/iOS. Установленные приложения получают их только после новой сборки и распространения; обновление сайта само по себе не заменяет установленный пакет.

## Последнее обновление: карта и полный демокаталог

В приложение включены 52 870 демолотов с описаниями, интерактивная карта с ближайшими лотами, радиусы поиска и заметное расстояние внутри лота. Карта использует OpenStreetMap и требует интернет для подложки. В футере есть политика конфиденциальности. Нативное меню отправки лота и вложенный возврат Android используют общую логику сайта; пользовательские объявления и фото остаются локальными. План сервера для высокой нагрузки — в `../docs/SCALING.md`; миллион одновременных пользователей пока не подтверждён испытаниями.

Поиск распознаёт русские и английские названия, уверенные опечатки и известную неверную раскладку. В формах легковых машин и грузовиков доступен справочник 521 марки и 8117 моделей. При запросе результаты идут по расстоянию; SITRAK C7H и КамАЗ 5490 представлены отдельными явно обозначенными региональными демопримерами; для КамАЗа используется иллюстрация категории, а не фотография другой марки.

ФАС торги позиционируется как Федеральная аукционная сеть для частных продавцов, компаний и банков по всей России. Наименование центра хранения в подвале относится к оператору площадки.

Категорийные иллюстрации оформлены в собственной палитре navy/azure/teal с медными деталями. Для окон, выбора категорий, кнопок и плиток добавлены короткие переходы. Анимации отменяются перед жестами и при настройке уменьшения движения; инерционная лента не получает анимации при перестройке буфера. Логика закрытия окон и Android «Назад» сохраняет синхронность.

Приложения Android и iPhone.

Размещение поддерживает форматы на повышение и на понижение. Во втором случае стоимость снижается по расписанию до заданного минимума, а покупатель принимает текущую цену; обычные ставки отключены. Оплата остаётся демонстрационной. Интерфейс использует общую шкалу мягких теней без изменения цветов логотипа и тяжёлых эффектов ленты.

В мобильном каталоге используется прокрутка всей страницы, освобождающая верх экрана для карточек. Персональная подборка учитывает избранное и открытые карточки; подходящие лоты идут строго от ближайших к дальним. Доступен режим «Все рядом», а состав текущего сеанса не переставляется от отметки просмотра или лайка. Кабинет содержит отдельную кнопку размещения. Центр уведомлений поддерживает сохранённые поиски и полученные обновления перебитых ставок, без имитации общего сервера торгов или доставки при закрытом приложении.

Поиск автоматически подбирает категорию по запросу и понимает варианты «Рав 4 / RAV4». В ленте есть однократное обучение жестам, таймер с пятью единицами времени и разнесённые метки. В размещении видимы адрес и координаты, их ссылка открывает карту с точкой. Повторы непроданных лотов без ставок выполняются при открытом сайте или возвращении в приложение; фонового круглосуточного планировщика нет. Внешние проверки автомобиля/недвижимости открывают официальный сервис и копируют номер, автоматическое заполнение чужих форм требует отдельной интеграции.

Годовая история продаж локальных объявлений, суммы, категории и CSV доступны на устройстве, включая нативный пакет без подключения к серверу. Отдельная серверная история принимает только исходные демолоты и требует входа; новые локальные и отредактированные объявления в неё автоматически не передаются. Общий счётчик пользователей также использует сервер сайта. В пакет не включаются серверный код или миграции; недоступные серверные показатели не подменяются вымышленными числами.

Кнопка «Купить лот» открывает демонстрацию карты, СБП, цифрового рубля и квитанции с получателем-продавцом. Реальный приём платежей и банковские QR не подключены; печатается только образец «НЕ ДЛЯ ОПЛАТЫ». Карточные данные не собираются, открытие оплаты не завершает торги.

Квитанцией можно поделиться как текстовым образцом. В Android/iOS используется официальный Capacitor Share; в браузере доступны системное меню, копирование или текст для ручного копирования. Отмена не запускает другие действия.

Поиск ключевых слов работает по всем видам имущества на русском и английском: название, описание, характеристики, продавец, регион, номера и условия. Окно категорий при просмотре также предлагает перейти к поиску лотов. У строки поиска есть микрофон и голосовые команды навигации; запись запускается пользователем. Поддержка SpeechRecognition зависит от браузера/WebView, при её отсутствии остаётся текстовый ввод. Голос не отправляет ставки и не удаляет данные.

Размещение начинается с категории, марки, модели и года. Подробные характеристики и дополнительные условия свернуты; название можно составить автоматически из своих данных, локацию взять из профиля. Ручные значения сохраняются. Справочник автомобилей содержит 521 марку и 8 117 моделей, работает в личном и банковском редакторе и загружается локально по необходимости. Источники и лицензия — в `dist/data/car-catalog-LICENSE.txt`; атрибуция VehiclesDB видима в интерфейсе.

Свайп слева направо во вложенном окне выполняет действие «Назад»: в категориях возвращает на уровень выше, в размещении сохраняет черновик и открывает кабинет, в подтверждениях возвращает к предыдущему шагу. Вложенные помощь и оценка закрываются отдельно. Текстовые поля, видео и горизонтальные галереи сохраняют собственные жесты.

Лента закрывается и свайпом влево по свободной области. На галерее выход влево доступен с последнего/единственного фото, а остальные кадры продолжают перелистываться. Выход вправо и вверх по верхней панели сохранён.

Удаление черновика сохраняет текущую вкладку и позицию списка: строка и счётчик меняются без повторного открытия кабинета. Очистка файлов выполняется отдельно и не возвращает пользователя назад. Техподдержка явно доступна в подвале сайта и под списком объявлений кабинета. Закрытие ленты учитывает неотменяемые мобильные события касания и быстрые свайпы; оба входа через кнопки проверены.

Центр помощи доступен из меню, подвала, карточки лота и размещения. В нём есть частые вопросы, телефон сайта и подготовка обращения с копированием текста; отправка сообщений через сервер не имитируется. Личную оценку продавца 1–5 и заметку можно сохранить, изменить или удалить на устройстве. Публичные подтверждённые отзывы ещё не подключены. Новые окна сохраняют открытую форму под ними и приостанавливают фоновое видео.

При размещении доступны списки года, марки, производителя, города и готового срока аукциона; для своих значений и нестандартного срока сохранён ручной ввод. Автосохранение объединяет ввод, а описание не запускает пересчёт всей формы. Каталог не пересчитывает все подписки при каждом поиске, избранное не сохраняет заново весь массив лотов, галереи обновляются не чаще одного кадра.

В ленте можно поделиться лотом без открытия карточки. Свайп вправо по свободной области/первому фото или вверх по свободной верхней панели закрывает ленту. Свайпы вверх/вниз по карточкам переключают имущество. Перелистывание остальных фото, видео и элементы управления имеют приоритет. Прокрутка остаётся нативной, а виртуальный буфер переставляется без анимации; настройка уменьшения движения учитывается.

В меню «Ещё» и карточке лота доступны «Недавно смотрели»: последние 12 доступных лотов сохраняются только на устройстве, историю можно очистить. Для демолотов есть точные ссылки, открывающие нужную карточку; доступ к сайту остаётся ограничен его настройками. Локальные объявления других пользователей не публикуются по ссылке — можно скопировать только номер.

Поиск объединяет быстрый набор с задержкой 180 мс и кеширует расстояния в пределах одного пересчёта. Окна получают доступные названия; запоздалый ответ входа не заменяет чужое окно. Демоставка подтверждается после записи на устройство, а сбой записи оставляет форму открытой. Банковские статусы, сроки, суммы и импорт проверяются до допуска лота к торгам. Общего сервера и реальных расчётов эти изменения не добавляют.

На главной подписка оформлена компактной заметной вкладкой перед списком лотов; в верхнем меню есть отдельная кнопка. Нажатие открывает сравнение бесплатного тарифа, Стандарта и Премиума. На вкладке указаны 500 ₽/месяц и скидка 20% на первый год при годовой оплате. Длинный блок тарифов убран с главной; статус демопросмотра и возврат к бесплатному режиму сохранены. Оплата остаётся отключённой.

Веб-сайт, устанавливаемая с сайта PWA и приложения Capacitor используют один интерфейс из `../dist`. В приложениях доступны каталог, вертикальная лента, горизонтальная галерея, поиск, локальное избранное по двойному нажатию, выбор региона и геолокация с разрешения пользователя. Кнопка Android «Назад» закрывает карточку, затем ленту. Видео останавливается при уходе приложения в фон.

Это демонстрационная версия с демонстрационными лотами. Избранное, фильтры и действия хранятся на устройстве и не синхронизируются между PWA, браузером и нативными приложениями. SMS, реальные аукционы, внешняя оценка имущества, платежи и серверная рассылка уведомлений ещё не подключены. Не используйте демонстрационные ставки как реальные сделки.

Добавлен кабинет частного продавца: кнопки «Продать» и «Кабинет», профиль, подробное объявление, черновики и локальная публикация. Аукцион длится от 1 часа до 30 суток; есть отложенный старт, фиксированный/процентный шаг, резерв, мгновенная демопокупка, задаток и ограниченное общим сроком автопродление. После публикации финансовые условия и сроки фиксируются. Пауза не переносит окончание, а после первой демоставки снимать лот или ставить его на паузу нельзя.

При просмотре доступна закреплённая панель «Лоты / Поиск / Продать / Избранное / Кабинет / Ещё». На телефоне она видна постоянно при просмотре, на компьютере появляется при уходе шапки с экрана. В формах и при вводе скрывается. В карточке лота есть отдельная панель возврата, избранного и перехода к ставке. Карточка закрывается свайпом вправо по описанию или первому фото; на следующих фото этот жест перелистывает галерею назад. Позиция фонового списка сохраняется.

Свайп вверх тоже возвращает к списку: начните его на фото, свободной части верхней панели или в конце описания. В середине текста жест продолжает прокрутку; кнопки, видео и поля ввода не закрывают карточку случайным движением.

В каталоге пять разделов: «Транспорт», «Недвижимость», «Товары для дома», «Электроника», «Бизнес и оборудование». У каждого подробные подкатегории и оригинальная предметная 3D-иллюстрация. Плитки адаптируются к ширине экрана: на телефоне две колонки, последняя широкая. Текст и изображения занимают отдельное место и не накладываются друг на друга. Кнопка «Все категории» открывает список с переходами к подкатегориям и поиском. Этот же выбор используется при размещении имущества частным продавцом и банком. Форма остаётся открытой под окном выбора, включая несохранённые данные.

По запросу владельца убраны работа, услуги, личные вещи, запчасти, хобби и животные. Они недоступны в поиске, выборе и размещении. Раздел «Товары для дома» восстановлен вместе с семью подкатегориями; ранее перенесённые домашние товары возвращаются по сохранённой классификации. Существующие лоты и черновики из остальных убранных разделов сохраняются в «Бизнес и оборудование → Прочее имущество»; прежняя явная подкатегория сохраняется как `previousSubcategory`. Старые восемь технических типов имущества сохраняются в `category`, точная классификация — в `subcategory`.

Выбранные пользователем фотографии и видео хранятся в IndexedDB данного браузера/WebView; метаданные кабинета — в localStorage. Это не серверная загрузка и не защищённая авторизация: другие посетители не видят объявления, а очистка данных приложения удалит кабинет и медиа. Лимит на объявление — 20 фото, 5 видео, вместе 100 МБ (фото до 10 МБ, видео до 30 МБ).

## Общая подготовка

Нужен Node.js 22 или новее. Из каталога `mobile` выполните:

```sh
npm ci
npm run sync
npm run check
```

`sync` копирует актуальный сайт в `www`, собирает нативный адаптер и обновляет оба проекта. Изменяйте сайт в `../dist`, а не в сгенерированном `www` или папках `public`.

## Android

Готовая тестовая APK: `../releases/fas-torgi-android-demo-debug.apk`. Это debug-сборка для проверки на телефоне, не релиз для Google Play. Идентификатор приложения: `ru.fastorgi.app`; минимальная версия Android — 7.0 (API 24), target/compile SDK — 36. Перед публикацией подтвердите право использовать идентификатор и выпустите подписанную релизную сборку.

Для повторной сборки установите Android Studio с Android SDK 36 и Build Tools 36, JDK 21 с `javac`. Укажите пути в `JAVA_HOME` и `ANDROID_HOME`, затем:

```sh
bash scripts/build-android-debug.sh
```

Для открытия проекта в Android Studio: `npm run android:open`. Ключи релизной подписи должны храниться вне репозитория.

## iPhone / iPad

Подготовлен проект `ios/App/App.xcodeproj` с зависимостями Swift Package Manager, иконками и описанием разрешения на геолокацию. Минимальная версия iOS — 15.4: интерфейс использует системные HTML-диалоги. На Mac с актуальной Xcode сначала выполните общую подготовку, затем:

```sh
npm run ios:open
```

В Xcode выберите Team в Signing & Capabilities, подтвердите Bundle Identifier и запустите на подключённом iPhone. Для распространения через TestFlight/App Store нужны аккаунт Apple Developer, подпись и Archive в Xcode. В Linux iOS-проект не компилировался; подписанная IPA не создавалась.

## Установка с сайта

PWA устанавливается из меню сайта «Установить приложение». На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой». Android использует установку браузера. Доступ к сайту по-прежнему ограничен текущими настройками владельца Sites. Установка не делает сайт общедоступным.

На сайте service worker не сохраняет HTML навигации, авторизацию, API, ставки и платежи. При отсутствии интернета он показывает общую страницу подключения. В нативные проекты вложены локальные демонстрационные данные и изображения; подключение боевых сервисов потребует серверной реализации.

## Проверено

Проверены синтаксис JavaScript, синхронизация общих ресурсов, конфигурация приложений, обработка двойного нажатия, сохранение фильтров и ограничения кеширования. Android APK собирается и проверяется инструментами Android SDK. Тестирование жестов на физических Android/iPhone и компиляция в Xcode остаются отдельными проверками перед релизом.
