# Локальное нейронное понимание запросов

Внедрён бесплатный encoder `Xenova/paraphrase-multilingual-MiniLM-L12-v2`, а не генеративная LLM. Свою базовую модель не обучали. Платный API, серверный ключ и внешний сервер обработки текста не нужны. Это осознанный выбор после реальных ошибочных ответов маленьких Qwen о правилах и оплате; исходные результаты сохранены в `reports/local-ai/rejected-generative-models.json`.

## Устройство и запуск

Страница подключает `dist/local-ai-policy.js`, затем `dist/local-ai.js` и `dist/local-ai.css`. Кнопка `data-local-ai-open` открывает панель и по явному клику переносит текущий `#voice-command` без автоматического выполнения. ASR останавливается, озвучивание помощника приостанавливается. Подложенные формы и их ставки не очищаются. Текст длиннее 450 символов не обрезается молча.

API `window.FasLocalAI`: `open({prefill:true})`, `close()`, `enable()`, `stop()`, `ask(text)`, `clearCache()`, `state()`. Вызов `open()` без опции не переносит голосовой текст. Стандартные точные команды предлагаются через штатный parser даже без скачивания. Только нажатие «Включить и скачать модель» создаёт dedicated module worker. Панель показывает около 150 МБ первого скачивания. Нет фонового запуска модели, камеры, микрофона и сетевых запросов при старте страницы.

`dist/local-ai-worker.js` работает на CPU через WebAssembly SIMD, один поток. WebGPU, SharedArrayBuffer и изменение глобальной CSP не нужны. Старый iOS 16.4 с известной проблемой SIMD отклоняется до скачивания. Недостаток памяти, места, недоступный CDN, ошибка SHA или загрузки дают понятный возврат к обычному помощнику. Реальное наличие ресурсов на конкретном телефоне определяется запуском, а не обещанием совместимости.

Веса преобразуют текст в нормализованный вектор из 384 чисел (`pooling: mean`, `normalize:true`). Максимальное сходство вычисляется для каждого разрешённого intent по 40 подготовленным примерам. Прототипы уже вычислены тем же ONNX и находятся в `dist/local-ai-prototypes.json`; при включении не требуется 40 повторных инференсов. Порог cosine — 0,50, отрыв от другого intent — 0,08. Ниже порога требуется уточнение. Изменение модели, pooling, нормализации или корпуса требует нового вычисления векторов, теста и SHA в worker.

Нейросеть возвращает только разрешённый intent. Основной поток повторно проверяет JSON и строит собственную подпись/команду. Сгенерированный текст отсутствует. Справка берётся из подготовленных строк с указанием разделов действующих документов. Деньги, необратимые действия, публикация, подтверждение ставки не исполняются. Ошибка модели может предложить неверный раздел, поэтому переход или поиск всегда требует кнопки пользователя и проверки штатным parser. Изменение запроса отменяет прежнее предложение поиска. Смена профиля удаляет запрос. Нельзя добавлять автоматическое выполнение результата модели.

## Закреплённые файлы и безопасность

Модель: ревизия `2c4055b12046f11709e9df2c122e59ffbdc2f900`, ONNX SHA-256 `66fc00f5f29afcaff34092e1bdd20008ca3918265a82fb9695a551e510cc4ebc`, размер 118 308 126 байт. Словарь — 17 082 913 байт. Все семь используемых артефактов (включая config, tokenizer_config, примеры, движок и WASM) перечислены с точными размерами и SHA в `FILES` worker. Загрузка сериализована и ограничена одним заранее выделенным буфером на файл; сборки массива всех чанков нет.

Движок `dist/vendor/transformers-2.17.2.min.js`: SHA-256 `bcf7cf304e51f470ed59409622b9d6ffbad80dfcf5baf6a40c919e4b9c4ff812`, 897 938 байт, около 203 КБ gzip. Движок импортируется из Blob только после проверки SHA. WASM jsDelivr версии 2.17.2: SHA-256 `9bd07bababc65f53d061f457233eeae501be7ceb8a2adb9eef52d87fe776d865`, 10 014 674 байта, проверяется до исполнения. Инференс использует только `ort-wasm-simd.wasm`, без потоков и proxy worker.

Fetch разрешает только точные закреплённые URL и GET. Внешние запросы: `credentials:omit`, `referrerPolicy:no-referrer`; внутренняя загрузка движка и прототипов использует `same-origin` для закрытого сайта. Содержимое запроса пользователя не включается в URL, тело или заголовки скачивания. Финальные допустимые хосты: собственный, jsDelivr, Hugging Face и `us.aws.cdn.hf.co`. Изменение CDN требует явной проверки, а не маски `*.hf.co`.

Только ответ `/local-ai-worker.js` получает CSP:

```text
default-src 'none'; script-src 'self' blob: 'wasm-unsafe-eval'; connect-src 'self' blob: https://cdn.jsdelivr.net https://huggingface.co https://us.aws.cdn.hf.co; worker-src 'none'; object-src 'none'; base-uri 'none'
```

Глобальная HTML CSP не разрешает обычный `unsafe-eval`. Артефакты хранятся исключительно в CacheStorage `fas-local-ai-artifacts-v1`. На каждом чтении проверяется SHA, поэтому повреждённый кеш не исполняется. «Удалить скачанную модель» очищает только этот кеш, без профиля, черновиков, фото и ставок. Закрытие, скрытие страницы, отмена и смена профиля завершают worker; поздние ответы проверяются по epoch и request id. Настройки реальных платежей и банка не связаны с моделью.

## Проверки и ограничения

`node tests/local-ai.cjs` проверяет отсутствие ранней загрузки, целостность и URL allowlist, credentials, ручное подтверждение, точные команды, экранирование текста, изменение запроса, отмену, профиль, скрытие страницы и изолированную очистку кеша. Это VM-тесты интерфейса/политики, а не браузерный инференс.

Реальные результаты в `reports/local-ai/`: одинаковые квантованные веса проверены через native CPU и `onnxruntime-web` WASM SIMD под Node. Чтобы принудительно проверить WASM, в временной копии Transformers.js исследователь переключил только выбор backend с Node на web; production-библиотека не патчилась. 38 отдельных русских запросов, 40 фиксированных примеров. 14 запросов приняты порогами, 13 из них классифицированы верно, 24 отклонены. Ошибка «Сотри мой профиль» предложила кабинет, после чего добавлен отдельный запрет разрушительных команд до нейросети. Эта выборка не гарантирует качество для любых формулировок. Совпадение CPU/WASM подтверждено для всех решений; максимальная разница пяти повторно вычисленных прототипов меньше 8,2e-8.

На исследовательской машине WASM отвечал за 12–23 мс после загрузки, а начальная загрузка уже скачанных файлов заняла около 2,68 с. Это измерение этой машины, не обещание скорости телефона. Браузер, физический iPhone, сетевой первый запуск и полный контур опубликованного сайта таким тестом не проверены. Для проверки перед публичным запуском нужны реальные браузеры и устройства: скачать/отменить, повторно открыть, запретить сеть, очистить кеш, исчерпать место, сменить профиль, свернуть приложение, возврат к форме ставки и проверка памяти.

Обновление: проверить лицензию, выбрать immutable revision, скачать и проверить файлы, пересчитать прототипы теми же весами, прогнать отдельный новый корпус, сверить WASM, обновить `FILES`, notice и отчёт. Не понижать пороги по результатам единственного тестового набора и не выдавать неуверенный ответ за установленный факт. Производственную зависимость не обновлять автоматически.

Дополнительно независимый проверяющий запустил текущий `local-ai-worker.js` с настоящим browser bundle Transformers.js, моделью, WASM и прототипами через `vm.SourceTextModule` в Node.
