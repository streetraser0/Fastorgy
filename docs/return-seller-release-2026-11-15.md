# Возврат из фото, продавец и действия с объявлением

Изменения после v68 (`577beedaaf14f8b91353fec4ccb87333511cd070`). Все данные пользователя и схемы хранения сохраняются; миграции базы не нужны.

## Как пользоваться

- В карточке лота первый кадр, включая единственное фото, позволяет вернуться свайпом вправо, если карточка прокручена к началу. На следующих кадрах такой жест листает фотографии назад. Просмотр увеличенного фото сохраняет собственные перелистывание, зум и возврат только к карточке.
- Нажатие на свободный фон возвращает через штатное действие верхнего окна. Поля формы, текст, фотографии и кнопки не считаются пустым фоном. Несохранённые данные проходят существующие проверки сохранения.
- На компьютере фотографии карточки переключаются по горизонтальным зонам при наведении курсора. Клик по фотографии открывает лот. На телефонах и в нативных оболочках остаются жесты.
- Сердечко и «Поделиться» в верхней подборке имеют общий круглый стиль: диаметр 32 px на desktop, значки 18 px. На touch-экранах видимый круг также компактный, но область нажатия остаётся 44 × 44 px. Сохранены выбранное состояние, клавиатурный фокус и правила отправки ссылок.
- Новый согласованный логотип: синяя пирамида со скруглёнными углами, наклонная надпись и подпись «Федеральная аукционная сеть» на прозрачном фоне. Точный исходник и воспроизведение PNG описаны в [документе логотипа](logo-blue-v2-2026-11-15.md).
- Цена находится перед характеристиками. Состояние и отсутствие задатка показываются непосредственно после цены; контактные и дополнительные действия расположены ниже.
- Нажмите на эмблему или имя продавца (например, «Демо-банк»), чтобы открыть его профиль. Для демонстрационных банков используется нейтральный знак банка; он не означает проверенную организацию.
- В форме объявления основное действие — «Отправить», рядом — «Сохранить черновик». Маленькая кнопка «Удалить» справа сначала запрашивает подтверждение. «Оставить черновик» сохраняет заполнение и фотографии. Удаление касается только выбранного черновика; опубликованный лот, ставки и файлы других объявлений сохраняются. Для лота с зафиксированными условиями остаётся название «Сохранить изменения».
- «Отправить» сохраняет прежнюю демонстрационную публикацию на текущем устройстве. Доставка объявлений другим пользователям или продавцам этим изменением не добавлена.
- В полноэкранной ленте рядом с участием есть действие покупки. При действующей указанной цене выкупа оно открывает существующий демонстрационный экран покупки. Иначе «Купить через торги» открывает карточку с условиями аукциона. Текущая ставка не превращается в цену мгновенного выкупа; свои и завершённые лоты защищены, существующее действие понижающихся торгов не дублируется.

| Действия редактора | `dist/seller-ui.js`, `dist/seller.css`; повторно используются подтверждение удаления и проверка конфликтов локального хранилища |
| Версии ресурсов | `dist/index.html` и `dist/sw.js`; нативная копия готовится через `mobile/scripts/prepare-web.mjs` |
| Логотип и компактные значки | `design/brand/fas-torgi-blue-master.svg`, `scripts/generate-brand-logo.mjs`, `dist/brand-contrast.css`, `dist/featured-lots.css`; старый мастер сохранён |

Удаление из редактора сначала сохраняет последние значения, затем открывает подтверждение. При ошибке записи удаление не продолжается. После успешного удаления `editor` очищается до перехода к черновикам, поэтому `leave()` и автосохранение не создают удалённую запись заново. Асинхронная очистка фотографий защищает ссылки остальных черновиков и опубликованных лотов. Старое подтверждение после смены экрана не действует.
